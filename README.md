# Hologram BeamOps Kanban

## Purpose

Build a Hologram-based Elixir application and take it through a
complete software delivery lifecycle, guided by Engineering Elixir
Applications.

## Project principles

- Use Hologram for the web application UI.
- Learn the complete lifecycle, not isolated chapter exercises.
- Keep development local until cloud deployment is planned and cost-checked.
- Prefer reproducible environments and infrastructure as code.
- Automate tests, builds, deployments, and operational checks where appropriate.
- Document architectural decisions and Hologram-specific adaptations.

## Lifecycle

1. Project planning and requirements
2. Application development
3. Automated testing and continuous integration
4. OTP releases and Docker
5. Local multi-service development
6. Infrastructure as code and AWS provisioning
7. Production deployment
8. Continuous deployment and secrets management
9. Distributed deployment
10. Scaling and deployment safety
11. Logging and metrics
12. Dashboards, alerts, and operational validation
